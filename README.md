# 飞机大战 ✈️💥

> 一个纯 HTML5 Canvas 打造的经典射击游戏，无需安装，打开即玩！

## 快速开始

用浏览器打开 `index.html`，战斗即刻开始！

```bash
git clone https://github.com/wangyanzhong9-coder/plane-war.git
cd plane-war
# 双击 index.html 或拖入浏览器即可
```

## 操控

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` / `W A S D` | 移动战机 |
| `空格` / `J` | 发射子弹 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始（游戏结束后） |

## 玩法

你的任务是**活下去**并**消灭一切来犯之敌**。

- 🛸 敌机从屏幕顶端不断涌来，撞到你或飞出屏幕底部都会损失生命
- ❤️ 拥有 **3 条命**，被击中后有短暂的无敌护盾
- 👾 **3 种敌人**轮番上阵——红色小飞机、橙色中型机、紫色重装机（带血条！）
- 📈 每获得 **1000 分**难度升级，敌人生成更快、更强
- 🏆 最高分自动保存在浏览器中，刷新页面也不会丢
- 💥 击中敌机迸发粒子爆炸，击毁时还有死亡烟花

## 技术

- 纯 **HTML + CSS + JavaScript**，零依赖
- 基于 `<canvas>` 的 2D 渲染
- `localStorage` 持久化最高分
- 原生 `requestAnimationFrame` 游戏循环
